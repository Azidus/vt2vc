Convert an OBJ file with UV-mapped image textures to a vertex-colored OBJ file for import into 3D print slicers like Bambu Studio or Orca Slicer, while preserving color information.

This tool only works with OBJ files that have an associated .mtl file and image texture. Other types of 3D files can be converted into OBJ format using free tools like Blender.

Simply drag and drop an .obj file into the program.
Alternatively, if you run vt2vc.exe by double-clicking it, the program will look for an OBJ file in the same folder and process it, outputting a new OBJ file with a name ending in _vertexcolor. This file can be directly imported into compatible slicers like Bambu Studio or Orca Slicer.
