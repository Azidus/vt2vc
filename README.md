Convert OBJ file with UV mapped image textures to vertex-colored OBJ file for import into 3D print slicers like Bambu Studio or Orca Slicer with preserved color information.

Only works with obj files with associated .mtl file and image texture. Other types of 3D files can be converted into obj using free tools like blender.
Simply drag and drop an .obj file into the program. 
Alternatively, if you run vt2vc.exe by double-clicking, the program will look for an obj file in the same folder and process it, outputting a new obj file with a name ending in _vertexcolor which can be directly imported into compatable slicers like Bambu Studio or Orca Slicer.
